# DT162G - Web Development with Javascript

Full-Stack Development with Node.js, NoSQL, MongoDB, JavaScript Frameworks, and JSON.

In this course, I worked extensively with CRUD applications in a JavaScript-based environment. I gained knowledge of Vue.js, Node.js, Express, and NoSQL databases like MongoDB with Mongoose. For the final  project, I developed a RESTful web service for managing courses and projects. The web service was built using Node.js and the Express framework, with MongoDB and Mongoose for database management. The Node.js application was deployed on Heroku, while the MongoDB database was hosted on mLab.
